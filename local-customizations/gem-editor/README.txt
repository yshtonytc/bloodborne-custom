存档宝石编辑：按原版表项转换

入口：启动器 → 存档 → 编辑存档宝石。
完全退出游戏，选择角色与宝石，直接选择主词条类别与数值档位，
再分别选择允许的副词缀和负面词缀，无需逐槽替换或挑整套固定预设。
打开宝石保留当前属性。改档位时保留仍适用的副词缀和诅咒，
超出新范围时使用该档位默认值，并在对照预览中显示所有改动。
“放弃此宝石修改”恢复原值；“备份并保存修改”需明确确认。
关闭或重新读取会放弃未保存修改，不写真实存档。

当前收录明确组合及冬灯分区域多档位规则，不是全游戏所有合法宝石的穷举。
冬灯水滴物理：噩梦边境 9.9%／11.6%，曼希斯噩梦 19%／19.8%，
渔村 20.6%／21.5%／22.3%。负面词缀在各自区域范围内独立选择，
六类负面各有该区域的数值档，不要求与主词条掷出同一效果档位。
原版形状支持水滴及放射／三角／欠月异形，不包含圆形；不能选27.2%。
无诅咒固定拾取15.8%独立，不能添加诅咒或正面副效果。
不再要求保留旧来源、旧档位或旧词条槽数：固定拾取宝石也可以转换。
27.2% 物理守望者宝石没有正面副效果，24.8% 深渊宝石有其对应副效果；
普通和减半诅咒分别约束，迷宫恶灵固定副词条的重复例外单独处理。
异形、异词条的低概率不能当作非法依据，但不能制造没有证据的滴液类型。
现有宝石未匹配表项时保持原样，可选已收录类型转换，不自动判非法或修正。
候选列表和保存后端使用同一整颗组合校验，不允许绕过界面混拼最大值。

只改六个效果 ID 的 24 字节，不改实例、数量、形状、来源标记或镶嵌关系。
保留来源标记可避免破坏背包引用；选择的表项 ID 单独记录在 gem-edit.json。
不改原游戏目录、后续掉落、血岩或宝石掉落 MOD。
仅支持 1.09 未加密角色存档，保存前后检查原生游戏进程并共享恢复锁。
完整备份进入 user/save-restore-safety/<时间>/，带文件 SHA-256，
可从“选择备份恢复”选回。先暂存、校验再交换目录，失败回滚。
只同步对应 backup 文件中整颗宝石及角色信息匹配的记录，不自动删备份。
